# Hobby site - react + typescript

Detta projekt är en enkel webbplats byggd med react och typescript.  


## Funktionalitet
- Sidhuvud med titel som skickas via props samt bannerbild
- Huvudinnehåll som renderar en lista dynamiskt baserat på data
- Varje objekt innehåller:
  - text (string)
  - nummer (integer)
  - boolean (true/false)
- Villkorsstyrd rendering med conditional operator
- Sidfot med information om utvecklare
- Responsiv design anpassad för både desktop och mobil

## Tekniker
- react
- typescript
- vite
- CSS 
- git och github
- netlify (publicering)
